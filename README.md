# 《敕令》 Edict

> 像素风国家建设与权力模拟游戏。**你不是在建设一个国家，你是在统治一群替你建设国家的人。**

基于《Songs of Syx》的玩法框架，核心创新在于**权力委任系统**：你可以把内政、军事、后勤授权给有性格、有私心的下属，他们可能办得很好，也可能中饱私囊，甚至反叛自立。

---

## 核心设计

| 系统 | 说明 |
|---|---|
| 行政容量 | 玩家能亲手管理的建筑有上限，逼你在"自己干"和"授权"之间做选择 |
| 官制 | 编制有限，领域可细分（农/工/商/财/民政/工程 + 统帅/军需/训练/斥候） |
| 贵族 | 六维性格，效用打分决策，隐藏忠诚度，有征兆的叛乱 |
| 叛乱 | 贵族叛乱（政治）与民众暴动（生存）两套系统，会互相引爆 |
| 战争 | 将军统帅、军需官补给，可征服或收服邻国 |

完整设计见 [`docs/DESIGN.md`](docs/DESIGN.md)。

## 目录结构

```
edict/
├── docs/
│   ├── DESIGN.md          设计宪法（唯一事实来源）
│   └── TECH.md            技术架构
├── art/
│   ├── STYLE.md           美术规范 v6
│   ├── palette/           40 色调色板（json / gpl）
│   └── tools/             参考图生成器
└── game/
    ├── project.godot      Godot 工程
    ├── Edict.csproj       C# 工程
    ├── scenes/            场景
    ├── locale/            中英文文本
    └── src/
        ├── Core/          纯逻辑，不依赖引擎，可脱离画面测试
        └── Godot/         引擎层：渲染、输入、界面
```

**架构铁律**：`src/Core/` 不允许 `using Godot;`。
逻辑与渲染解耦后，才能做无头加速模拟测试——这是调平衡的唯一可行办法。

## 运行

需要 **Godot 4.7.2 (.NET 版)** 与 **.NET 8 SDK**。

```bash
cd game
dotnet build
# 用 Godot 打开 game/project.godot，或：
# Godot_v4.7.2-stable_mono_win64.exe --path game
```

**操作**：中键拖拽 / WASD 平移，滚轮缩放，F5 存档，F9 读档，空格切换速度。

## 美术

像素风，投影方案为**屋顶 + 南墙**（斜俯视）。

| 资源 | 尺寸 |
|---|---|
| 地形瓦片 | 48 × 48 |
| 建筑 | 144 / 192 |
| 角色 | 32 × 32（俯视，单帧） |
| 头像 | 256 × 256 |
| 调色板 | 40 色 |

生成参考图：

```bash
python art/tools/gen_style_sheet.py
```

详见 [`art/STYLE.md`](art/STYLE.md)。

## 技术栈

- **引擎**：Godot 4.7.2 (.NET)
- **语言**：C# / .NET 8
- **模拟**：固定步长 10 tick/s，与渲染解耦
- **存档**：JSON + gzip，带 schema 版本号
- **本地化**：全 key 化，中英双语，禁止硬编码文本
