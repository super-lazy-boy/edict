## 0. 总原则：默认继承希克斯之歌

本作是《Songs of Syx》的加强版，**美术风格默认继承，不重新发明**。

| 继承（不改） | 说明 |
|---|---|
| 低饱和土色系 | 整体压暗，颜色不跳 |
| 纯俯视 | 只看得到屋顶，不露墙面 |
| 重描边 | 1px 深色轮廓，与地形分离 |
| 双色抖动 | 用两色交错做纹理，不用渐变 |
| 元素小而密 | 建筑 2×2 到 4×4 瓦片 |

**只在这些地方明确改进**：

| 改进 | 原因 |
|---|---|
| 瓦片 32 → **48** | 32 画不下屋瓦、木纹、窗框 |
| 建筑 64 → **96/144/192** | 同上，建筑需要更多细节 |
| 头像 128 → **256** | 头像要能看出性格 |
| 建筑零件化拼装 | Syx 手绘整栋，40 栋 = 40 张图；零件化后只需十几个零件 |
| 职业用服装色区分 | Syx 市民辨识度偏低 |
| 取消角色逐帧动画 | 省下的工换更多建筑 |

## 2. 调色板（32 色）

| 组 | 色名 | 用途 |
|---|---|---|
| 暗部 | `ink0`–`ink3` | 描边、阴影、深色背景 |
| 石 | `gray0`–`gray2` | 石材、城墙 |
| 骨白 | `bone0`–`bone1` | 界面文字、纸、布 |
| 绿 | `green0`–`green5` | 草地、森林、农田 |
| 水 | `blue0`–`blue3` | 水面、窗玻璃 |
| 土 | `earth0`–`sand1` | 泥土、沙地、路面 |
| 木 | `wood0`–`wood3` | 木材、结构 |
| 赤 | `red0`–`red1` | 屋顶、旗帜 |
| 权贵 | `purple`、`gold0`–`gold1` | 贵族、王权、金钱 |

**约束**：
- 一种材质最多用 **3 个相邻色阶**
- `gold0`/`gold1` 是稀有强调色，只用于王权、金钱、重要按钮
- 大面积区域用 `green3` 以下、`earth1` 以下的暗色

## 3. 纯俯视的建筑画法（核心规则）

**建筑只画屋顶，不画任何墙面。**

从上往下看，一栋双坡屋顶建筑的结构：

```
┌────────────────────────┐
│  上坡屋面（受光）        │  基色 red1，顶边 wood3，底边 red0
├────────────────────────┤
│  屋脊（1–2px 亮 + 暗）   │  wood1 / wood3
├────────────────────────┤
│  下坡屋面（背光）        │  基色 red0，顶边 red1，底边 ink2
├────────────────────────┤
│  檐口                    │  wood1
└────────────────────────┘
```

### 3.1 屋瓦画法（最容易画错的地方）

✅ **正确**：横向叠瓦
- 每行高 7px
- 行顶 1px 亮线，行底 1px 暗线
- 行底上每隔 14px 画一条 **3px 短竖线**，隔行错开

❌ **错误**：通长竖线
> 通长竖线在像素画里等于**砖缝**，整栋楼会读成砖墙。这是 v2/v3 的失败原因。

### 3.2 坡面明暗

- 上坡（朝光）：`red1`
- 下坡（背光）：`red0`
- 两者差值必须肉眼可辨，否则屋顶会变成一块平板

### 3.3 其他元素

- 烟囱：画在屋面上，带 1px 投影和黑色烟口
- 天窗：小矩形，`blue1` 玻璃 + `blue3` 反光
- 投影：向**右下**偏移 6–7px，透明度 75%

## 4. 地形瓦片

6 种：草地、森林、水面、沙地、岩石、土路。

- **无描边**，必须无缝拼接
- 每类准备 **3 个随机变体**
- 纹理用**双色抖动**（棋盘格撒点），不用渐变、不用噪点
- 禁止画明显图案（草叶、花朵、石子）——大地图上会变噪点

---

## 5. 角色（静态，无逐帧动画）

**本作不做角色动画。**

| 项目 | 规定 |
|---|---|
| 尺寸 | **24 × 32** |
| 帧数 | **1 帧**（正面）+ 1 帧（背面），左右用程序翻转 |
| 视角 | 俯视：头顶（头发色）+ 肩背（服装色） |
| 朝向 | 用前方一小块面部提示 |
| 移动 | 程序位移，可选 1px 上下浮动（零美术成本） |

### 职业配色

| 职业 | 主色 |
|---|---|
| 农民 | `green3` |
| 工匠 | `wood2` |
| 商人 | `blue2` |
| 士兵 | `gray1` |
| 官员 | `purple` |
| 贵族 | `purple` + `gold0` 头发 |

所有职业共用同一骨架，只换颜色。**新增职业零美术成本。**

## 6. 界面

| 项目 | 规定 |
|---|---|
| 图标 | **24 × 24** |
| 面板底色 | `ink1`，90% 不透明 |
| 边框 | 1px `ink3`；强调用 `gold0` |
| 正文字号 | 最小 **14 px** |
| 字体 | 中文：微软雅黑；英文：Inter |

**界面不用像素字体**——中文像素字体可读性差。界面现代、世界像素，对比是刻意的。

## 8. AI 生成分工

| 素材 | 做法 | 理由 |
|---|---|---|
| **贵族头像** | ✅ AI 生成 | 约束少、成功率高 |
| **界面图标** | ✅ AI 生成 | 单物件，成功率高 |
| 地形瓦片 | 程序生成 | 一致性要求极高 |
| 建筑 | 程序生成零件 + 拼装 | AI 整栋生成透视必然失控 |
| 角色 | 程序生成 | 单帧，程序更快更准 |

### 后处理流水线（AI 资源必做）

1. 降采样到目标尺寸（最近邻）
2. 量化到 32 色调色板
3. 去抗锯齿
4. 补 1px `ink0` 描边
5. 目视验收

### 验收"四看"

1. **看颜色**——是否全在 32 色内
2. **看描边**——是否 1px、颜色统一
3. **看光源**——高光是否在左上
4. **看像素**——放大后是否全是硬边方块
