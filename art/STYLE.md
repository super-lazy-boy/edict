## 0. 参考与改进

**从希克斯之歌拿过来的：**

| 特征 | 说明 |
|---|---|
| 低饱和土色系 | 整体压暗，颜色不跳，有苍凉感 |
| 屋顶主导的顶视角 | 你看到的是**屋面**，不是建筑的正面墙 |
| 重描边 | 建筑和角色有 1 像素深色轮廓，和地形分离 |
| 双色抖动 | 用两色交错做纹理，不用渐变 |
| 元素小而密 | 单栋建筑占 2×2 到 3×3 瓦片，不夸张 |

**我要改进的：**

| 改进 | 原因 |
|---|---|
| 32 色硬约束 | Syx 的色数偏松，导致不同素材色调不统一 |
| 建筑零件化拼装 | Syx 是手绘整栋，40 栋建筑 = 40 张图；零件化后只需十几个零件 |
| 职业用服装色区分 | Syx 的市民辨识度偏低，玩家分不清谁在干什么 |
| 界面现代化 | Syx 的界面偏老旧，字号小、信息密度过载 |
| 取消逐帧动画 | 省下大量美术工，用程序位移替代 |

## 1. 总则

| 项目 | 规定 |
|---|---|
| 瓦片尺寸 | **32 × 32**，永不改变 |
| 缩放方式 | 只允许**整数倍**（1× / 2× / 3× / 4×） |
| 采样 | **最近邻**，禁止线性过滤（关掉抗锯齿） |
| 视角 | **顶视角**：建筑以屋顶为主，仅露出南侧一段墙体 |
| 光源 | **左上 45°**，高光在左上，阴影落右下 |
| 描边 | **1 像素**，颜色 `ink0 #0E0D10`，只用于建筑/角色/图标 |
| 色数 | 严格限制在 **32 色**内 |

**三条最容易犯的错**：
1. 用了调色板外的颜色（尤其是"稍微亮一点"的变体）
2. 描边不是 1 像素，或者描边颜色不统一
3. 画成了"正立面 + 三角屋顶"——**这是错的**，本作是顶视角

## 2. 调色板（32 色）

| 组 | 色名 | 用途 |
|---|---|---|
| 暗部 | `ink0`–`ink3` | 描边、阴影、深色背景 |
| 石 | `gray0`–`gray2` | 石材、城墙、金属 |
| 骨白 | `bone0`–`bone1` | 界面文字、纸、布 |
| 绿 | `green0`–`green5` | 草地、森林、农田 |
| 水 | `blue0`–`blue3` | 水面、窗户玻璃 |
| 土 | `earth0`–`sand1` | 泥土、沙地、路面 |
| 木 | `wood0`–`wood3` | 木材、建筑结构 |
| 赤 | `red0`–`red1` | 屋顶、旗帜 |
| 权贵 | `purple`、`gold0`–`gold1` | 贵族、王权、金钱 |

**用法约束**：
- 一种材质最多用 **3 个相邻色阶**
- `gold0`/`gold1` 是**稀有强调色**，只用于王权、金钱、重要按钮
- 禁止用 `bone1` 做大面积底色（会刺眼）
- 整体亮度要压低：**大面积区域用 `green3` 以下、`earth1` 以下的暗色**

## 3. 地形瓦片

6 种基础地形：草地、森林、水面、沙地、岩石、土路。

- **无描边**，必须能无缝拼接
- 每类地形准备 **3 个随机变体**，避免大范围重复感
- 纹理用**双色抖动**（棋盘格交错撒点），不用渐变、不用噪点

**禁止**：在地形瓦片里画明显图案（草叶、花朵、石子）——会在大地图上形成噪点。

## 4. 建筑

### 4.1 尺寸档位

| 档位 | 像素 | 用途 |
|---|---|---|
| 1×1 | 32×32 | 井、栅栏、路标、摊位 |
| 2×2 | 64×64 | 民居、作坊、仓库 |
| 3×3 | 96×96 | 宫殿、兵营、大市场 |

### 4.2 顶视角画法（重要）

一栋建筑从上往下看，结构是：

```
┌──────────────────┐
│   屋面（受光）    │  ← 上坡，用亮色
├──────────────────┤  ← 屋脊，1–2px 深色横线
│   屋面（背光）    │  ← 下坡，用暗色
├──────────────────┤  ← 檐口，1px
│   墙体（南侧）    │  ← 只露这一条，5–12px 高
└──────────────────┘
```

- **不要**画山墙（三角形正面）
- 屋面占建筑高度的 **60–70%**
- 墙体只露南侧一条，用来放门和窗
- 烟囱画在屋面上，带 1px 投影

### 4.3 零件库

| 类别 | 零件 |
|---|---|
| 屋面 | 受光屋面、背光屋面、屋脊、檐口 |
| 墙体 | 木墙、石墙、砖墙 |
| 门窗 | 木门、铁门、小窗、格窗 |
| 附加 | 烟囱、旗帜、招牌、水桶、柴堆、栅栏 |

**拼装顺序**：`投影 → 墙体 → 屋面 → 屋脊 → 檐口 → 门窗 → 装饰 → 描边`

### 4.4 投影

建筑向**右下**投 **4 像素**阴影（`ink0`，透明度 27%）。

## 5. 角色（静态，无逐帧动画）

**本作不做角色动画。** 这是刻意选择，省下的美术量用来多做建筑和界面。

| 项目 | 规定 |
|---|---|
| 尺寸 | **16 × 20**（脚底在画布底部） |
| 帧数 | **1 帧**（正面）+ 1 帧（背面），左右用程序翻转 |
| 描边 | 1 像素 `ink0` |
| 移动表现 | **程序位移**，可选 1 像素上下浮动（不占美术） |

### 5.1 结构

```
头（8×8，含头发）
躯干（肩宽 8，腰宽 6）
双臂（各 2×6）
双腿（各 2×4）
```

### 5.2 职业用服装颜色区分

| 职业 | 主色 |
|---|---|
| 农民 | `green3` |
| 工匠 | `wood2` |
| 商人 | `blue2` |
| 士兵 | `gray1` |
| 官员 | `purple` |
| 贵族 | `purple` + `gold0` 头发/饰物 |

**所有职业共用同一套骨架**，只换颜色。这样新增职业零美术成本。

## 6. 界面

| 项目 | 规定 |
|---|---|
| 图标尺寸 | **16 × 16**，整数倍放大 |
| 面板底色 | `ink1`，不透明度 90% |
| 面板边框 | 1 像素 `ink3`；强调面板用 `gold0` |
| 正文字号 | 最小 **14 px** |
| 标题字号 | 20–24 px |
| 字体 | 中文：微软雅黑 / 思源黑体；英文：Inter |

**界面不用像素字体**（中文像素字体可读性差）。界面走"清晰现代"，游戏世界走"像素复古"，两者对比是刻意的。

## 7. 贵族头像

| 项目 | 规定 |
|---|---|
| 尺寸 | **128 × 128** |
| 构图 | 半身，胸口以上，正面或微侧 |
| 背景 | `ink1` 底 + `ink2` 横纹 |
| 边框 | 2 像素 `gold0` |
| 要素 | 必须能一眼看出性格（眉眼、嘴形、服饰） |

## 8. AI 生成工作流

### 8.1 分工（v2 定稿）

| 素材 | 做法 | 理由 |
|---|---|---|
| **贵族头像** | ✅ **AI 生成** | 约束少、成功率高、最能体现性格 |
| **界面图标** | ✅ **AI 生成** | 16×16 单物件，成功率高 |
| 地形瓦片 | 程序生成 | 一致性要求极高 |
| 建筑 | 程序生成零件 + 拼装 | AI 整栋生成透视必然失控 |
| 角色 | 程序生成 | 只有 1 帧，程序更快更准 |

### 8.2 提示词模板（头像 / 图标）

```
pixel art portrait, 128x128, half body, [personality descriptor],
limited muted palette, dark background, gold frame,
1px dark outline, light from upper-left, no anti-aliasing,
flat shading, no text, no watermark
```

### 8.3 后处理（必做）

1. **降采样**到目标尺寸（最近邻）
2. **量化**到 32 色调色板
3. **去抗锯齿**（清除半透明边缘）
4. **描边**（统一补 1px `ink0`）
5. **目视检查**（见 8.4）

脚本：`art/tools/postprocess.py`（待实现）

### 8.4 验收"四看"

1. **看颜色**——是否全部落在 32 色内
2. **看描边**——是否完整 1 像素，颜色是否统一
3. **看光源**——高光是否在左上
4. **看像素**——放大后是否全是硬边方块

## 10. 验收清单

- [ ] 尺寸正确（32 / 64 / 96 / 16×20 / 128）
- [ ] 颜色全部在 32 色内
- [ ] 描边 1 像素，颜色 `ink0`
- [ ] 光源左上
- [ ] 无抗锯齿、无半透明边缘
- [ ] **建筑是顶视角，不是正立面**
- [ ] 建筑由零件拼装，非整栋生成
- [ ] 角色是单帧静态，无动画帧
- [ ] 地形可无缝拼接，纹理用双色抖动
- [ ] 文件名符合命名规则
