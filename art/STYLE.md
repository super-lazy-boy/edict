# 《敕令》美术规范 v1.0

> 参考图：`art/preview/style_sheet.png`（由 `art/tools/gen_style_sheet.py` 生成）
> 调色板：`art/palette/palette.json`、`art/palette/edict32.gpl`
> 本规范是**验收依据**。任何资源不符合以下任一条，一律打回。

---

## 1. 总则

| 项目 | 规定 |
|---|---|
| 瓦片尺寸 | **32 × 32**，永不改变 |
| 缩放方式 | 只允许**整数倍**（1× / 2× / 3× / 4×） |
| 采样 | **最近邻**，禁止线性过滤（关掉抗锯齿） |
| 视角 | **3/4 俯视**（斜上方 45°），统一，不允许混用 |
| 光源 | **左上 45°**，高光在左上，阴影落右下 |
| 描边 | **1 像素**，颜色 `ink0 #14121A`，只用于建筑/角色/图标 |
| 色数 | 严格限制在 **32 色**内 |

**三条最容易犯的错**：
1. 用了调色板外的颜色（尤其是"稍微亮一点"的变体）
2. 描边不是 1 像素，或者描边颜色不统一
3. 光源方向不一致——同一个画面里有的左上打光，有的右上

---

## 2. 调色板（32 色）

| 组 | 色名 | 用途 |
|---|---|---|
| 暗部 | `ink0`–`ink3` | 描边、阴影、深色背景 |
| 灰部 | `gray0`–`gray2`、`paper` | 石材、界面文字 |
| 绿 | `green0`–`green5` | 草地、森林、农田 |
| 水 | `blue0`–`blue3` | 水面、窗户玻璃 |
| 土石 | `earth0`–`sand1` | 泥土、沙地、路面 |
| 木 | `wood0`–`wood3` | 木材、建筑结构 |
| 赤金 | `red0`–`red2` | 屋顶、旗帜、危险提示 |
| 权贵 | `purple`、`gold0`–`gold1` | 贵族、王权、界面强调 |

**用法约束**：
- 一种材质最多用 **3–4 个相邻色阶**（如木材用 `wood0`/`wood1`/`wood2`）
- `gold0`/`gold1` 是**稀有强调色**，只用于王权、金钱、重要按钮
- 禁止用 `paper` 做大面积底色（会刺眼）

---

## 3. 地形瓦片

6 种基础地形：草地、森林、水面、沙地、岩石、土路。

- **无描边**，必须能无缝拼接
- 每类地形准备 **3 个随机变体**，避免大范围重复感
- 变体之间差异要小（只改几个像素的散布），否则会出现"补丁感"

**禁止**：在地形瓦片里画明显的图案（如草叶、花朵）——会在大地图上形成噪点。

## 4. 建筑

### 4.1 尺寸档位

| 档位 | 像素 | 用途 |
|---|---|---|
| 1×1 | 32×32 | 井、栅栏、路标、小摊位 |
| 2×2 | 64×64 | 民居、作坊、仓库 |
| 3×3 | 96×96 | 宫殿、兵营、大市场 |

### 4.2 零件库（模块化拼装）

**建筑不整栋生成，由零件拼装。** 这样 40 种建筑只需要十几个零件，风格天然统一。

| 类别 | 零件 |
|---|---|
| 地基 | 石基、木台、土夯 |
| 墙体 | 木墙、石墙、砖墙 |
| 屋顶 | 茅草顶、木瓦顶、石瓦顶 |
| 门 | 木门、铁门、大门（双开） |
| 窗 | 小窗、大窗、格窗 |
| 装饰 | 烟囱、旗帜、招牌、水桶、柴堆 |

### 4.3 拼装顺序

```
地基 → 墙体 → 门窗 → 屋顶 → 装饰 → 描边 → 投影
```

### 4.4 投影

建筑右下方向投 **4 像素**半透明阴影（`ink0`，透明度 35%）。

## 5. 角色

| 项目 | 规定 |
|---|---|
| 尺寸 | **16 × 24**（脚底在画布底部中央） |
| 朝向 | 4 方向（下/上/左/右），左右可镜像 |
| 行走动画 | **4 帧** |
| 待机动画 | **2 帧**（轻微呼吸起伏） |
| 描边 | 1 像素 `ink0` |

**职业区分靠服装颜色**，不靠体型——保证所有市民共用一套骨架动画。

| 职业 | 主色 |
|---|---|
| 农民 | `green3` |
| 工匠 | `wood2` |
| 商人 | `blue2` |
| 士兵 | `gray1` + `red1` |
| 官员 | `purple` |
| 贵族 | `purple` + `gold0` |

---

## 6. 界面

| 项目 | 规定 |
|---|---|
| 图标尺寸 | **16 × 16**，整数倍放大 |
| 面板底色 | `ink1`，不透明度 90% |
| 面板边框 | 1 像素 `ink3`；强调面板用 `gold0` |
| 正文字号 | 最小 **14 px** |
| 标题字号 | 20–24 px |
| 字体 | 中文：微软雅黑 / 思源黑体；英文：Inter |

**界面不用像素字体**（中文像素字体可读性差）。界面走"清晰现代"，游戏世界走"像素复古"，两者对比是刻意的。

---

## 7. 贵族头像

| 项目 | 规定 |
|---|---|
| 尺寸 | **128 × 128** |
| 构图 | 半身，胸口以上，正面或微侧 |
| 背景 | `ink1` 底 + `ink2` 斜纹 |
| 边框 | 2 像素 `gold0` |
| 要素 | 必须能一眼看出性格（表情、服饰、姿态） |

头像是**唯一允许超出 32 色倾向的地方**——但仍建议控制在 32 色内以保持统一。

## 8. AI 生成工作流

### 8.1 分工建议（诚实评估）

| 素材 | 推荐做法 |
|---|---|
| 贵族头像 | **AI 生成**，效果最好 |
| 界面图标 | **AI 生成**，成功率高 |
| 地形瓦片 | 程序生成 + 人工微调 |
| 建筑 | **零件程序生成 + 拼装**（AI 整栋生成一致性差） |
| 角色动画 | 程序生成骨架 + 手绘关键帧 |

> **理由**：AI 生成"一整栋像素建筑"时，透视和色数几乎必然失控；但生成"一个头像"或"一个图标"时，约束少、成功率高。把 AI 用在它擅长的地方。

### 8.2 提示词模板

```
pixel art, 32x32 tile, top-down 3/4 view, limited palette,
single [object], centered, transparent background,
1px dark outline, light from upper-left, no anti-aliasing,
flat shading, no text, no watermark
```

### 8.3 后处理（必做）

生成图必须经过以下流水线，缺一不可：

1. **降采样**到目标尺寸（最近邻）
2. **量化**到 32 色调色板（逐像素映射到最近色）
3. **去抗锯齿**（清除半透明边缘像素）
4. **描边**（按第 1 节规则统一补 1px `ink0`）
5. **目视检查**（见 8.4）

后处理脚本：`art/tools/postprocess.py`（待实现）

### 8.4 验收"四看"

拿到任何一张资源，先看这四点：

1. **看颜色**——是否全部落在 32 色内
2. **看描边**——是否完整 1 像素，颜色是否统一
3. **看光源**——高光是否在左上
4. **看像素**——放大后是否全是硬边方块，有没有模糊过渡

四条全过才算合格。

## 9. 文件组织

```
art/
├── palette/          palette.json, edict32.gpl
├── tiles/            terrain.png（6 类 × 3 变体，横向排列）
├── buildings/        house.png, farm.png, warehouse.png, ...
├── parts/            墙、顶、门、窗等零件
├── characters/       villager_*.png
├── ui/               icons.png（图标图集）
├── portraits/        noble_*.png
├── preview/          style_sheet.png
└── tools/            gen_style_sheet.py, postprocess.py
```

**命名规则**：全小写，下划线分隔，不用中文文件名。

## 10. 验收清单

- [ ] 尺寸正确（32 / 64 / 96 / 16×24 / 128）
- [ ] 颜色全部在 32 色内
- [ ] 描边 1 像素，颜色 `ink0`
- [ ] 光源左上
- [ ] 无抗锯齿、无半透明边缘
- [ ] 地形可无缝拼接
- [ ] 建筑由零件拼装，非整栋生成
- [ ] 文件名符合命名规则
