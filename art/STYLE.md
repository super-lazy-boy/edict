## 0. 风格基准

**投影方案 C：屋顶 + 南墙**（希克斯之歌式斜俯视）。

```
┌──────────────────────────┐
│  上坡屋面（受光）          │  基色 red2，顶边 red3，底边 red1
├──────────────────────────┤
│  屋脊                     │  wood2 / wood4
├──────────────────────────┤
│  下坡屋面（背光）          │  基色 red1，顶边 red2，底边 red0
├──────────────────────────┤
│  檐口 → 在墙上投下暗带     │  ink2 + 抖动过渡
├──────────────────────────┤
│  南墙（木构架 + 门 + 窗）   │  墙色 bone0，柱梁 wood2
└──────────────────────────┘
```

**三个明暗层次是立体感的来源**，不是靠堆细节：

```
屋面（受光/背光） → 檐口阴影 → 墙面
```

**继承希克斯之歌的部分**：低饱和土色、重描边、双色抖动、元素小而密。
**改进的部分**：瓦片 48、建筑 144/192、40 色、零件化拼装、取消角色动画。

## 2. 调色板（40 色）

| 组 | 色阶数 | 用途 |
|---|---|---|
| 暗 `ink0-3` | 4 | 描边、阴影 |
| 石 `gray0-4` | 5 | 石材、城墙、金属 |
| 骨白 `bone0-1` | 2 | 墙面、纸、界面文字 |
| 绿 `green0-5` | 6 | 草地、森林、农田 |
| 水 `blue0-3` | 4 | 水面、窗玻璃 |
| 土 `earth0-2 / sand0-2` | 6 | 泥土、沙地、路面 |
| 木 `wood0-4` | 5 | 木材、结构 |
| 赤 `red0-3` | 4 | 屋顶、旗帜 |
| 权贵 `purple / gold0-1` | 3 | 贵族、王权、金钱 |
| 肤 `clay0` | 1 | 皮肤 |

**为什么从 32 扩到 40**：32 色撑不住写实阴影。灰补到 5 级、赤补到 4 级、木补到 5 级之后，阴影才能画出**过渡**而不是两块硬色。

## 3. 建筑画法（关键规则）

### 3.1 屋瓦：横向叠瓦

✅ **正确**
- 每行高 8px
- 行顶 1px 亮线，行底 1px 暗线
- 行底上每隔 16px 一条 **3px 短竖线**，隔行错开

❌ **错误：通长竖线**
> 通长竖线在像素画里等于砖缝，整栋楼会读成砖墙。

### 3.2 南墙

- 高度约占建筑 **30%**
- 竖向木柱 4–5 根，宽 6px
- 上下横梁各 6px
- 门居中偏左，宽约 17%
- 窗对称，22×20，`blue2` 玻璃 + `blue3` 反光条

### 3.3 阴影（写实感的来源）

| 阴影 | 做法 |
|---|---|
| 投影 | 右下偏移 8–9px，透明度 95，边缘抖动软化 4px |
| 檐口阴影 | 墙上顶 7px 实心 `ink2` + 下方 5px 抖动过渡 |
| 墙脚 | 底部 5px `earth0` |
| 内缘 AO | 结构交界处向内压暗 |

## 4. 地形

6 种：草地、森林、水面、沙地、岩石、土路。

- **无描边**，必须无缝拼接
- 每类 3 个随机变体
- 纹理用双色抖动，不用渐变
- 禁止明显图案（草叶、花朵），大地图上会变噪点

## 6. 界面

| 项目 | 规定 |
|---|---|
| 图标 | 24 × 24 |
| 面板底 | `ink1`，90% 不透明 |
| 边框 | 1px `ink3`，强调用 `gold0` |
| 正文字号 | ≥ 14 px |
| 字体 | 中文微软雅黑；英文 Inter |

界面不用像素字体——中文像素字体可读性差。**界面现代、世界像素**，对比是刻意的。

## 7. 人物头像（点击角色时弹出）

| 项目 | 规定 |
|---|---|
| 尺寸 | **256 × 256** |
| 构图 | 半身，胸口以上 |
| 背景 | `ink1` + `ink2` 横纹 |
| 边框 | 2px `gold0` |
| 要求 | 一眼看出性格 |

**写实靠阴影分面**，五个必画区域：

1. 额头受光（`sand2`）
2. 颧骨下方阴影（`earth2`）
3. 眼窝阴影（`earth2`）
4. 鼻侧阴影 + 鼻孔（`earth2` / `ink2`）
5. 唇下阴影（`earth2`）
