# 《敕令》 Edict —— 设计宪法

> 本文档是项目的唯一事实来源。任何实现与本文冲突，以本文为准；任何规则修改，先改本文，再改代码。
> 版本：v0.2　最后更新：2026-11-08

---

## 一、一句话定位

**你不是在建设一个国家，你是在统治一群替你建设国家的人。**

玩家从一个村的工匠，成长为必须依赖下属的国王。授权省下的是你的时间，付出的是失控的风险。

---

## 二、核心循环

```
定方针 → 授权贵族 → 观察执行 → 干预或放任 → 忠诚度变化 → 叛乱/晋升 → 重新授权
```

玩家永远在做一个选择：

| 自己干 | 交给贵族 |
|---|---|
| 结果可控 | 省时间 |
| 消耗行政容量 | 结果有偏差 |
| 规模做不大 | 有背叛风险 |

**这个跷跷板就是整个游戏。**

---

## 三、权力结构

```
国王（玩家）—— 绝对权力，可随时介入任何层级
  │
  ├── 文官系统（按领域划分）
  │     ├── 农业官 ─┐
  │     ├── 工业官  │
  │     ├── 贸易官  ├── 各设：大臣（一级）／地方官（二级）／吏员（三级）
  │     ├── 财政官  │
  │     ├── 民政官  │
  │     └── 工程官 ─┘
  │
  └── 武官系统
        ├── 将军（统帅）
        ├── 军需官（后勤）
        ├── 训练官
        └── 斥候（情报）
```

- 任何职位**允许空缺**。空缺的代价由玩家本人承担（见 4.3）。
- 玩家可任命、罢免、升降任意层级官员。
- 下级必须服从上级，权力随层级递减。
- **官制本身是玩家可编辑的**（见第六章）。

## 四、四条铁律

### 4.1 玩家拥有最终编辑权

任何政策、任何方针，玩家随时可改写、推翻、细化。**没有玩家改不了的规则。**

### 4.2 钦定不可推翻

玩家亲手放置的建筑、亲自下达的命令，标记为「钦定」：

- 贵族不能拆除
- 贵族不能改变用途
- 贵族不能降低其优先级

这是硬约束，在数据层强制，不依赖 AI 自觉。

### 4.3 空缺即自负

职位空缺时，其职责**不会自动完成**。玩家必须亲手执行，且持续占用行政容量。
不任命，就得自己扛；扛不住，就爆。

### 4.4 叛乱即割据

贵族宣布叛乱后，该领地的**政策面板对玩家关闭**：

- ❌ 不能修改方针
- ❌ 不能任命/罢免该地官员
- ❌ 不能直接拆除建筑
- ✅ 可以派兵攻打
- ✅ 可以断供（贸易封锁）
- ✅ 可以外交施压
- ⚠️ 情报受限（详见 8.4）

叛乱不是"换个老板"，是**领土从你的行政系统中被切掉一块**。

## 五、行政容量（核心资源）

### 5.1 定义

**行政容量**：玩家能亲手管理的建筑/区域数量上限。

- 基础值由宫殿等级决定
- 玩家每亲自管理一个建筑，占用 1 点
- 指派给官员管理的建筑，**不占用**玩家容量

### 5.2 超载惩罚

超出上限时：

- 全城生产效率下降（每超 1 点 −3%，累计）
- 民怨缓慢上升
- 官员消极（忠诚度下降）

### 5.3 三阶段曲线

| 阶段 | 规模 | 玩家在玩什么 |
|---|---|---|
| 早期 | 一个小村（< 20 建筑） | 自己动手，玩建设 |
| 中期 | 一座城（50–150 建筑） | 被迫授权，玩管理 |
| 后期 | 一个帝国（多城） | 管人不管事，玩政治 |

**玩家从"工匠"变成"国王"，是被系统逼出来的，不是剧情安排的。**

## 六、官制系统（权力结构的可调节性）

### 6.1 编制

- 官职不是无限设的，受**编制**限制（由宫殿等级决定）
- 玩家自由设岗：**领域 × 层级**
- 每个岗位消耗俸禄（钱），且占据 1 个编制

**玩家实际在玩的是：用有限的编制，填哪几个领域。**

### 6.2 三个调节维度

| 维度 | 玩家的选择 |
|---|---|
| **数量** | 设几个岗？多则臃肿，少则积压 |
| **领域** | 补哪块短板？农业？贸易？工程？ |
| **文武比例** | 偏文还是偏武？看局势 |

### 6.3 官员过少的代价

- **事务积压**：待办队列变长，完成率下降
- **响应延迟**：事件处理变慢（灾害、袭击反应不及）
- **真空**：没人管的领域，玩家必须亲自上，**占用行政容量**
- **失控**：偏远地区治安下降、税率收不上来

### 6.4 官员过多的代价

- **俸禄开支**：财政压力
- **政令衰减**：层级每多一层，命令执行偏差 +8%
- **内斗**：官员形成派系，互相拉低忠诚度
- **腐败滋生**：冗余岗位是贪腐的温床
- **背叛源增加**：每个官员都是一个潜在叛乱点

> 关键：**官多不只是花钱，是增加了政治风险。** 这是"多设官"真正的代价。

### 6.5 负载率模型

```
事务需求 D = f(人口, 建筑数, 辖区面积)
官员处理能力 C = Σ(每个官员的能力值)
负载率 ρ = D / C
```

| 负载率 | 状态 |
|---|---|
| ρ < 0.5 | 冗官，浪费俸禄，内斗滋生 |
| **0.7 ≤ ρ ≤ 0.9** | **最优区间**（留余量应对突发） |
| 0.9 < ρ ≤ 1.0 | 紧绷，勉强应付 |
| ρ > 1.0 | 积压，事务完成率断崖下跌 |

### 6.6 领域细分

**文官六域**（各自独立计算负载率）：

| 领域 | 管什么 | 崩了会怎样 |
|---|---|---|
| 农业 | 农田产出、仓储损耗、灌溉 | 全城饿死 |
| 工业 | 采矿、冶炼、加工效率 | 建材断供，建不动 |
| 贸易 | 商队、关税、物价 | 缺的东西买不到，多的卖不掉 |
| 财政 | 税收、国库、俸禄发放 | 发不出俸禄 → 官员忠诚暴跌 |
| 民政 | 住房、医疗、治安、民怨 | 民怨飙升 → 暴动 |
| 工程 | 建造速度、道路、城墙 | 什么都慢，城墙修不完 |

**武官四域**：

| 领域 | 管什么 |
|---|---|
| 统帅 | 军队战斗力、战术 |
| 军需 | 补给线、粮草、装备 |
| 训练 | 新兵素质、士气 |
| 斥候 | 情报、预警、叛乱征兆的发现 |

> **斥候这一域很关键**：不设斥候，你就看不见贵族叛乱的征兆。这是"省钱"和"保命"的取舍。

### 6.7 文武平衡

**不是固定比例，是看局势。**

| 状态 | 后果 |
|---|---|
| 文多武少 | 军队补给差、士气低、边防虚弱、被侵略时无还手之力 |
| 武多文少 | 军费拖垮财政、经济停滞、民怨上升 |
| 武将权重过高 | **政变风险上升**（将军手里的兵就是他的本钱） |
| 战争时期 | 武官需求激增，此时偏文会被打穿 |
| 和平时期 | 武官冗余，纯属烧钱 |

**设计意图**：让玩家每隔一段时间就要重新审视自己的组织结构。没有一劳永逸的配置。

## 七、两套叛乱系统

### 7.1 贵族叛乱（政治）

**触发三要素，缺一不可：**

1. 忠诚度跌破阈值（隐藏值）
2. 手里有本钱（兵、钱、地盘）
3. 时机合适（民怨高、外敌压境、玩家虚弱）

**叛乱倾向随层级递减：**

| 层级 | 叛乱倾向 |
|---|---|
| 大臣 | 高 |
| 地方官 | 中 |
| 基层吏员 | 极低（单独反叛几乎不可能） |

基层要反，必须有：上级带头，或外国撑腰，或全城已乱。

**征兆必须可见**（但不能太明显）：招兵、囤粮、与外国通信、拒绝执行命令、频繁巡视边境。
**发现征兆依赖斥候。**

### 7.2 民众暴动（生存）

**唯一触发条件：活不下去。**

- 不是瞬间归零，是「饥饿忍耐度」累积到临界
- 不分层级，全城同时
- 一旦爆发，会吸引叛乱的贵族收编

### 7.3 两套系统的耦合

```
贵族贪腐 → 吞掉粮食 → 百姓饥饿 → 民暴 → 贵族趁乱自立 → 领地割据
```

**这条链子必须能自然发生。** 这是本作最好玩的部分。

### 7.4 叛乱后的情报衰减

割据领地对玩家变成半黑箱：

- 可见：建筑轮廓、人口总数（粗略）
- 不可见：库存细节、军队动向、内部政策
- 需要：间谍、商队、边境观察才能恢复情报

## 八、贵族人格系统

### 8.1 性格维度（0–100）

| 维度 | 高 | 低 |
|---|---|---|
| 勤勉 | 事必躬亲，效率高 | 拖延、敷衍 |
| 贪婪 | 中饱私囊 | 清廉 |
| 野心 | 扩张、揽权 | 安分 |
| 忠诚 | 忠于国王 | 见风使舵 |
| 谨慎 | 稳扎稳打 | 冒险激进 |
| 慷慨 | 善待百姓 | 苛刻 |

### 8.2 决策方式：效用打分

每隔一段时间，贵族列出「我能做的事」，逐条打分，选最高分执行。

```
得分 = 基础收益 × 性格权重 × 玩家方针 × 当前局势
```

### 8.3 意图日志（不可省略）

每次行动必须生成一句人话，写进日志：

> 「李牧：国库告急，我加征了三成税。城里有些人不太高兴。」

**没有这个，玩家会觉得游戏在自己玩自己，信任崩塌，整个系统失效。**

## 九、国风系统

每局开局选择一个国度。国风**不改变核心规则**，而是改变权力系统的运作方式——同样是授权，稷下靠官僚，狼原靠武力，众议靠程序。

### 9.1 六国

| 国 | 英文 | 风格 | 独特能力 | 代价 |
|---|---|---|---|---|
| **稷下** | Jixia | 文治 | 文官负载上限 +20%，行政容量 +15% | 武将忠诚每回合 −1 |
| **狼原** | Wolfplain | 武威 | 军力 +25%，征召速度 +30% | 农业 −15%，贵族叛乱倾向 +20% |
| **潮汐** | Tide | 商道 | 贸易收入 +40%，仓储损耗 −50% | 人口自然增长 −20% |
| **磐石** | Bedrock | 营造 | 建造速度 +35%，城墙强度 +50% | 全部官职俸禄 +25% |
| **香火** | Incense | 信仰 | 民怨上升 −40% | 工业产出 −20%，官员派系形成速度 +30% |
| **众议** | Assembly | 共和 | 贵族叛乱概率 −50% | 政策生效延迟 +30%，行政容量 −20% |

### 9.2 设计原则

1. **每个国风都同时有强项和代价**，没有纯优势
2. **代价必须咬在核心循环上**——不是"少 10% 产出"这种无关痛痒的数字，而是让你改变玩法
3. 稷下逼你走文官路线、狼原逼你打仗、潮汐逼你贸易、磐石逼你盖城、香火逼你维稳、众议逼你慢决策

### 9.3 数值实现

所有国风通过一组**修正系数**作用于系统，不写特例代码：

```
行政容量 / 文官效率 / 军力 / 农业 / 工业 / 贸易 / 建造速度
民怨增长 / 贵族忠诚漂移 / 叛乱概率 / 俸禄成本
```

## 十、水域与通行

水不是墙，是**有代价的路**。

### 10.1 三种通行方式

| 方式 | 通行代价 | 速度 | 风险 |
|---|---|---|---|
| 陆地 | 10 | 100% | 无 |
| 游泳 | 40 | 40% | 每 tick 0.03% 概率溺水 |
| 渡口航道 | 12 | 100% | 无 |

A* 按代价寻路，所以市民**天然倾向走陆地**——只有当绕路成本超过 4 倍时才会下水。

### 10.2 溺水

- 每 tick（0.1 秒）判定一次，概率 0.0003
- 换算：游 10 秒约 3%，游 30 秒约 9%
- 死亡个体退出模拟，但保留在数组里（不压缩，避免索引失效）

### 10.3 渡口

- 只能建在水面，且 2 格内必须有岸
- 建成后覆盖半径 3 的水域为安全航道
- 航道内不溺水、速度正常、代价接近陆地

**设计意图**：湖泊从"地图上的空洞"变成"值得投资的基础设施"。修一座渡口，等于给城市开了一条捷径。
